# Biblioteca completa de elementos (15 famílias × 4 produtos × 2 fundos)
É o kit inteiro do estúdio, gerado da ficha da marca (cores, traço, fontes e raios do manual). Cada produto tem a sua cor:
`todos` = **marca-mãe, dourado** (página-mãe e as três juntas) · `biomecanica` = azul · `bodybuilding` = vermelho ·
`feminino` = roxo.

## Como achar o que precisa
1. Abra a **folha** da família em `<produto>/fundo-escuro/_folha-<familia>.jpg` (ou `fundo-claro`): cada elemento aparece
   com nome e nota.
2. Pegue o **SVG** no `<produto>-svg.zip` (pasta `fundo-escuro/<familia>/NN-nome.svg`). `_indice.csv` lista nome, nota e
   tamanho de cada arquivo.

## Famílias
| família | para que serve |
|---|---|
| assunto | instrumentos do tema do produto (goniômetro, barra, anilha, fita, anel, planos, prumo…) |
| dados | numerais, contadores, progresso, calendário, "pague 1, leve 2" |
| codigos | códigos de barras/QR-like, selos de código, marcas de registro |
| faixas | tarjas, faixas, marquises, fitas de rodapé |
| fios | linhas, réguas e divisórias |
| formas | formas geométricas básicas da campanha |
| grades | grades, malhas, polares |
| linhas | traços e cortes |
| pontos | padrões de pontos, meio-tom |
| texturas | texturas e grãos |
| profundidade | sombras, relevos, camadas |
| colagem | recortes, fitas, rasgos, sobreposições |
| selos | selos, carimbos, etiquetas |
| mao | traços à mão |
| tipograficos | letras e números como elemento gráfico |
| exemplo | composições de exemplo |

## Regras
- Use a cor do **produto certo** (não misture dourado nas páginas de professor).
- Os SVGs não têm texto vivo (letras em curvas); os nomes dos arquivos não aparecem na arte.
- Elementos de campanha ficam retos; só conteúdo (cartão, painel, foto) leva canto arredondado.
- Para o que **já está aplicado nas páginas**, veja `../<produto>/` (lista curada com a explicação de cada uso).
